# Graphs

Generated by `tools/make-graphs.py` (01 to 09, repository data only), `tools/make-verification-figures.py` (10, 11) and `tools/make-recording-graphs.py` (needs the recordings):

- **Real data:** `data/rew/*.txt` (REW sweeps of 19 Oct 2026, before any DSP).
- **Computed:** the exact filter sets, alignment table and height tone filters in `scripts/set-eq.py`.
- **Quoted values:** summary numbers written in `docs/status.md`, `docs/alignment.md` and `docs/tuning-log.md`.
- **Real recordings:** figures 03, 06 (range), 07, 08, 08b and 12 to 19 are drawn by `tools/make-recording-graphs.py` from the raw recordings
  (sweep1/sweep2, sub-sweep, subtest-hot, dlg1, Tenet direct/drone2, Dolby Amaze, direct2/thump20x/tight20x). The recordings are not in the repository; run
  `python3 tools/make-recording-graphs.py --help` for the options. The pan test has no analyser yet, so it is not redrawn.
