# Graphs

Generated by `tools/make-graphs.py` (01 to 09) and `tools/make-verification-figures.py` (10, 11). Both read this repository only:

- **Real data:** `data/rew/*.txt` (REW sweeps of 19 Oct 2026, before any DSP).
- **Computed:** the exact filter sets, alignment table and height tone filters in `scripts/set-eq.py`.
- **Quoted values:** the summary numbers written in `docs/status.md`, `docs/alignment.md`, `docs/tuning-log.md` and the measurement reports of
  2026-10-21 to 2026-10-24. The raw recordings (sweep runs 1 and 2, sub test, pan test, Tenet, dialogue, reflections) are not in the repository, so the
  curves that need them (per-speaker tone against the bed, the heights bass curves, the timing scatter, the pan-test evenness, the hot sub test) are not redrawn here.
  To redraw them, put the recordings in a local folder and run the analysers in `tools/sweeptest`, `tools/subtest`, `tools/dialoguetest` and `tools/reflecttest`.
